
# PLP Python Week 7 Assignment

This repository contains my Python Week 7 file handling and CSV report builder assignment.

## Files

- my_notes.py - Writes, appends, reads and counts notes.
- my_notes.txt - Contains the four saved notes.
- report_builder.py - Reads CSV data and generates a learner report.
- hubs.csv - Contains learner names, hubs and scores.
- report.txt - Contains the generated learner report.

## File Modes

If I change "a" (append mode) to "w" (write mode), Python will erase the existing three notes before writing the fourth note. The file would contain only the fourth note.
